# Gravity Run — Telegram Mini App

لعبة سباق جاذبية عمودية ضد بوت، مصممة للموبايل وتعمل داخل المتصفح أو Telegram Mini App.

## اللعب
- المس ساحة اللعب أو اضغط `Space` لتبديل الجاذبية والانتقال إلى الجدار المقابل.
- تفادَ الحواجز التي تظهر بالتناوب من الجانبين.
- أكمل المراحل الثلاث: المجرة الزرقاء، غابة النعناع، وصحراء الشمس.
- إذا اصطدمت بعقبة تخسر؛ إذا اصطدم البوت أو أكملت المراحل الثلاث تفوز. لا توجد نقاط.

## التشغيل
لا توجد عملية بناء أو اعتماديات. افتح `index.html` مباشرة، أو قدّم الملفات عبر أي استضافة مواقع ثابتة مثل GitHub Pages أو Netlify أو Render Static Site. أضف رابط الموقع إلى إعدادات Telegram Mini App لفتحه من البوت.

## الملفات
- `index.html` — صفحة اللعبة وواجهة Telegram Web App.
- `style.css` — تصميم متجاوب للشاشات العمودية.
- `game.js` — الرسم على Canvas، حركة اللاعبين والبوت، مراحل اللعبة والتصادم.

الشخصيات مرسومة كرسوم vector أصلية في Canvas ولا توجد صور أو أصول من اللعبة المرجعية.
